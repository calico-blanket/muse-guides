# Muse ガイド集

## 内容

- **manual/** ―「Muse Manual」
  技術書スタイルの取扱説明書。本文・画面の名称・会話と記憶の仕組みなどを簡潔にまとめた版です。
- **welcome/** ―「Museの使い方」
  初めて Muse を使う人向けの入門ページ。部屋をめぐりながら基本の使い方を案内します。
- **token-guide/** ―「Museのトークン入門」
  トークンの仕組みと、無料／有料の区別を説明するページです（利用状況の数字は一般的な表示例に置き換えてあります）。
- **tutorial/** ―「動画風チュートリアル」
  9つの場面で Muse の使い方を紹介する、動画風アニメーションのページです。
- **long-conversations/** ―「長い会話とトークン」
  会話が長くなるとトークン消費と応答の質にどう影響するか、その対応策をまとめたページです。
- **complete-guide/** ―「Muse Complete Guide」
  初心者向けの総合説明書（可愛い版）。全8章＋付録で、基本操作からメモリーの手入れまでを案内します。
- **github-guide/** ―「MuseでGitHubにプッシュする手順」
  Muse Manual の別冊。GitHubアカウントの作成から Muse との接続、リポジトリの選び方、承認、プッシュまでをまとめた手順書です。
- **kappie-dance.mp4**
  アシスタント「カッピー」が踊る短い動画です。

## 注意

個人が作った非公式のガイドです。Muse（Meta）の公式資料ではありません。
